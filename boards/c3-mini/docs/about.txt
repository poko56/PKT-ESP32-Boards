PKT ESP32-C3 Mini (Rev A)
บอร์ดจิ๋วสำหรับงานไร้สาย เน้นเล็กและไฟสะอาด พร้อมโลโก้ POKOTEAM ด้านหลัง

== เรื่องราวของบอร์ด (เรื่องเล่า แต่งขึ้น) ==
ทีม PKT เคยเจอปัญหาที่น่ารำคาญที่สุดของงานไร้สาย คืออุปกรณ์ที่คุยกันดีๆ อยู่แล้วหลุดไปเฉยๆ
พวกเขาจึงกลับมาตั้งคำถามกับพื้นฐาน: ไฟต้องเงียบ เสาอากาศต้องโล่ง และตัด
ทุกอย่างที่ไม่จำเป็นออก ผลลัพธ์คือบอร์ดขนาดเท่านิ้วมือตัวนี้ เล็กจนซ่อนในอุปกรณ์ได้เกือบทุกชนิด
แต่ยังมี USB-C ในตัว เสียบแล้วเขียนโปรแกรมได้เลย

== ใช้ทำอะไรได้บ้าง ==
- โหนด ESP-NOW หรือ Wi-Fi ขนาดเล็ก เช่น ตัวส่งข้อมูลเซนเซอร์
- อุปกรณ์สวมใส่หรืออุปกรณ์ติดตั้งในกล่องขนาดเล็ก
- รีโมตไร้สาย และบอร์ดรับส่งข้อมูลระหว่างอุปกรณ์
- งาน Bluetooth LE

== จุดเด่นของวงจร ==
- USB ในตัวชิป ไม่ต้องใช้ชิป USB-UART เพิ่ม
- ไม่มีวงจรสวิตชิงบนบอร์ด ใช้ LDO AP2112K-3.3 ผ่าน ferrite กรองไฟเข้า
- มีไดโอด B5819W กันไฟย้อนเข้า USB และ USBLC6 ป้องกัน ESD
- ไม่มีทองแดงใต้เสาอากาศ โลโก้บริเวณนั้นเป็นแค่หมึก silkscreen
- มี thermal via ที่ EPAD ของโมดูล และเชื่อม ground ด้านบนกับล่าง

== สเปก ==
ขนาดบอร์ด     20 x 34 มม. PCB 2 ชั้น
โมดูล         ESP32-C3-MINI-1 (13.2 x 16.6 มม.)
ไฟเข้า        USB-C หรือขา 5V
ขา I/O        header 7 ขา 2 แถว ห่างกัน 15.24 มม. (เสียบ breadboard ได้)
             GPIO 0-7, 10, TX, RX, 3V3, GND, 5V
ปุ่มและไฟ      RST, BOOT, LED ที่ IO8 (ติดเมื่อขาเป็น LOW)
การประกอบ      อุปกรณ์ SMD อยู่ด้านเดียว header บัดกรีเอง

== ถ้า ESP-NOW หลุด ควรเช็ก firmware ด้วย ==
บอร์ดใหม่ช่วยเรื่องไฟและเสาอากาศ แต่สาเหตุที่พบบ่อยหลายอย่างอยู่ฝั่งซอฟต์แวร์
- ทุกตัวต้องอยู่ channel เดียวกัน ถ้าตัวหนึ่งต่อ Wi-Fi router มันจะย้าย channel ตาม
- ปิด Wi-Fi power save: esp_wifi_set_ps(WIFI_PS_NONE)
- ใช้ wifi mode ให้ตรงกันทั้งสองฝั่ง (เช่น STA)
- เช็กสถานะใน send callback และทำ retry กับ heartbeat
- อย่าทำงานนานใน callback ให้ส่งเข้าคิวแล้วไปทำที่ task อื่น
- ส่งถี่เกินไปหรือใช้ peer เกินจำนวนที่รองรับจะทำให้แพ็กเก็ตหาย
- อย่าวางเสาอากาศชิดโลหะ แบตเตอรี่ หรือสายไฟ

== สถานะ ==
DRC: ไม่มี error ลายเชื่อมครบทุกจุด เหลือแต่ warning เรื่อง silkscreen และ thermal relief
ERC: ผ่าน 0 รายการ และ schematic ตรงกับ PCB
พร้อมส่งไฟล์เข้า JLCPCB แต่ยังไม่ได้ทดสอบกับบอร์ดจริง
ground ด้านหลังยังมีลายสัญญาณผ่านบางส่วน เพราะบอร์ดเล็กและมี 2 ชั้น
ผลลดการหลุดของ ESP-NOW ต้องวัดจากบอร์ดจริง ยังยืนยันไม่ได้
