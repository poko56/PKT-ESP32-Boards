PKT ESP32 Robot Arm Controller (Rev B)
บอร์ดควบคุมแขนกล 5 แกนสำหรับ servo ขนาดเล็ก SG90/MG90S ออกแบบในนาม POKOTEAM

== เรื่องราวของบอร์ด (เรื่องเล่า แต่งขึ้น) ==
แขนกลตัวแรกของทีม PKT ขยับได้ไม่กี่วินาทีก็สั่นและบอร์ดรีเซ็ตเอง เพราะ servo กระชากไฟ
จน ESP32 ไฟตก ทีมจึงตั้งโจทย์ใหม่ว่า "แรงไปที่แขน ความนิ่งอยู่ที่สมอง" และแยกไฟของสองส่วน
ออกจากกันตั้งแต่แรก บอร์ดนี้จึงเกิดขึ้น พร้อมปุ่มหยุดฉุกเฉินที่ตัดไฟ servo ทันทีเมื่อจำเป็น
และจะไม่จ่ายไฟให้แขนจนกว่า firmware จะพร้อมสั่งเปิด

== ใช้ทำอะไรได้บ้าง ==
- ควบคุมแขนกลตั้งโต๊ะ 5 แกน
- งานหยิบวาง สาธิต หรือโครงงานหุ่นยนต์ในสถาบันการศึกษา
- อ่านตำแหน่งจากโพเทนชิออมิเตอร์ และอ่าน limit switch เพื่อหาจุดเริ่มต้น
- สั่งงานไร้สายผ่าน Wi-Fi หรือ Bluetooth และวัดกระแสเพื่อดูว่า servo ทำงานหนักเกินไหม

== จุดเด่นของวงจร ==
- PWM จาก PCA9685 แยกจาก CPU ลดอาการ servo สั่น
- บัฟเฟอร์ 74AHCT541 ยกสัญญาณเป็น 5V และกันชิปหลักจากปลายสาย servo
- ไฟ servo ใช้บัค TPS54560B ส่วนไฟ logic ใช้ AP63205 แยกต่างหาก ผ่านไดโอดและ
  ตัวเก็บประจุ hold-up
- E-stop แบบ fail-safe: สายหลุดหรือกดหยุด ไฟ servo ดับ และบูตมาจะดับเป็นค่าเริ่มต้น
- วัดกระแสและแรงดันราง servo ด้วย INA219 และวัดแรงดันเข้าด้วย ADC

== สเปกตามแบบ ==
ขนาดบอร์ด     80 x 64 มม. PCB 2 ชั้น
ไฟเข้า        adapter 12V (ออกแบบรับ 9-16V) แจ็ค DC
ราง servo     5V ใช้งานต่อเนื่องประมาณ 3-4 A
พอร์ต servo    5 ช่อง เรียงขา S / + / -
พอร์ตเสริม     DIO 5, ADC 4, I2C 2, UART 1, ESTOP 1
หมายเหตุ       ต้องต่อสวิตช์ NC หรือจั๊มเปอร์ที่พอร์ต ESTOP ไม่เช่นนั้น servo จะไม่ได้ไฟ

== สถานะ ==
ยังสั่งผลิตไม่ได้ ตัววงจรผ่าน ERC (เหลือ error ของ V3 บน CH340C ที่ตั้งใจไว้)
แต่การเดินลายอัตโนมัติยังไม่สำเร็จหลังลอง 40 รอบ จึงยังไม่มี Gerber
ภาพ pcb_placement_top.png คือการวางอุปกรณ์ ยังไม่ใช่บอร์ดที่เดินลายครบ
ค่าวงจรชดเชยของบัคอ้างอิง datasheet ของ TI แต่ยังไม่ได้ทดสอบกับบอร์ดจริง
