PKT ESP32 Dev Board (Rev A)
บอร์ดพัฒนา ESP32 สำหรับต่อ breadboard ออกแบบในนาม POKOTEAM

== เรื่องราวของบอร์ด (เรื่องเล่า แต่งขึ้น) ==
ทุกโปรเจกต์ใหญ่เริ่มจากบอร์ดเล็กๆ บนโต๊ะ ทีม PKT ต้องการบอร์ดตัวแรกที่หยิบมาเสียบ
USB-C แล้วเริ่มทำงานได้ทันที ไม่ต้องต่อสายวุ่นวาย ไม่ต้องกดปุ่มตอนอัปโหลดโค้ด
Dev Board ตัวนี้จึงกลายเป็น "บอร์ดคู่โต๊ะ" สำหรับลองไอเดียใหม่ทุกวัน ตั้งแต่ไฟกะพริบ
ดวงแรก ไปจนถึงเซนเซอร์ที่ส่งข้อมูลขึ้นอินเทอร์เน็ต

== ใช้ทำอะไรได้บ้าง ==
- เรียนรู้และทดลองเขียนโปรแกรม ESP32 ด้วย Arduino หรือ PlatformIO
- ทำต้นแบบอุปกรณ์ IoT, Wi-Fi และ Bluetooth
- อ่านเซนเซอร์และควบคุมอุปกรณ์ภายนอกผ่านขา GPIO
- ใช้เป็นบอร์ดสอนในห้องเรียนหรือเวิร์กช็อป

== สเปกจริง ==
ขนาดบอร์ด     29 x 54.6 มม. PCB 2 ชั้น
โมดูล         ESP32-WROOM-32E
USB           USB-C ผ่าน CH340C พร้อมวงจร auto-reset
ไฟเลี้ยง       5V จาก USB ผ่าน SS14 และ AMS1117-3.3
ปุ่มและไฟ      ปุ่ม EN, BOOT, LED PWR, LED ที่ IO2
ขา I/O        header 17 ขา 2 แถว ห่างกัน 25.4 มม.

== สถานะ ==
DRC: ไม่มี error มี warning 2 จุดจาก silkscreen ของ USB-C ที่ยื่นพ้นขอบ
ERC: error 1 รายการโดยตั้งใจ (ขา V3 ของ CH340C ต่อ VCC ตาม datasheet ที่ไฟ 3.3V)
มี Gerber พร้อมสั่งผลิต แต่ยังไม่ได้ทดสอบกับบอร์ดจริง
